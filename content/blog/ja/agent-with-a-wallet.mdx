お金を使えるエージェントを初めて作ると、二つのことが同時に起こる。一つは小さい — エージェントが二分おきに「続けていいですか？」と聞いてこなくなる。もう一つは大きい — エージェントが「あなたのもの」であることを役に立つ意味で **やめて**、それ自体になる。世界に出ていって、支払い、リトライし、必要なツールを取りに行き、答えを持って戻ってくる存在に。

その二つ目こそが、私たちが本当に売っているものだ。ウォレットではない。ウォレットは手段だ。私たちが売っているのは **ハードキャップ付きの自律性**。これがチャットボットと従業員の違いだ。

## 定額サブスクリプションが本当に課金しているもの

月額 20 ドルの AI ツールを思い出してほしい。先週どれくらい使ったか。三日は開きもしなかった。ある一日、長いエージェントループを走らせた — 正直に課金されていれば、推論コストだけで 6 ドルかかった処理。プラットフォームが吸収したのは、他の八人のユーザーがカーソルが点滅するのを見るだけで月額 20 ドルを払っていたからだ。

サブスクリプションは **プールリスク商品** だ。ヘビーユーザーがライトユーザーに補助される。Netflix では機能する — 視聴は時間が有界で、配信コストは 20 ドルの請求額に対してセント単位の端数だ。自律エージェントでは機能しない:

- 一人のユーザーがリサーチループを回して二時間で焼く額が、その人の月額より多くなる
- プラットフォームの唯一の防衛策はレート制限で、最悪のタイミングで発動する
- 持続可能な均衡点は **全員が劣化する** — 価格がプラットフォームから見て「公正」に感じられるまで

これはあなたも体験している。1 月は鋭かった Sonnet が、4 月にはなまっている。先週はタスクを完遂していたエージェントが、今週は途中で止まって「新しいチャットで続けてください」と言う。これはバグではない。意図された通りに数学が働いている。

## ウォレットが変えるもの

エージェントに自分のウォレットを与える — お守りすべき会社カードではなく、本物のオンチェーン残高でエージェント自身が制御するもの — と、交渉構造全体が反転する。

サービスへの **アクセス時間** ではなく、**測定可能でその価値に見合った成果** に対して支払うようになる。エージェントは他のユーザーと共有のレート制限プールを争わない。一回ずつ自分で支払う、セント単位で正確に。プロバイダもすべてのモデルを鈍らせる必要がなくなり、ヘビータスクをためらわず提供できる。

Franklin はこれを具体的にするために作った。USDC 残高 — 5 ドル、20 ドル、100 ドル、好きな額で — を保持し、55 以上のモデル、画像生成、ウェブ検索、トレーディングデータ、ツールにわたって自律的に消費する。すべての呼び出しは [x402 マイクロペイメント](/docs/user-guide/smart-router) で USDC 決済される。API キーなし、最低月額なし、サブスクリプションなし。ウォレットが空になればエージェントは止まり、リチャージするか聞いてくる。それだけだ。

<Callout type="tip" title="5 秒のテスト">
あなたの AI ツールの故障モードが「Continue を押すまで動かなくなった」と説明できるなら、あなたは定額制でレーション配給されている商品にお金を払っている。ウォレット駆動のエージェントは、お金が尽きることでしか故障しない — 正直で、明白で、修復は些細: USDC をリロードするだけ。
</Callout>

## 「コール毎課金」は売り文句ではない

技術的に正しい言い方は「USDC 上の x402 で決済される従量課金 API」。これは正しいが、売れない。

肩をすくめて「あれ、ちょっと待って」と言わせる本当の売り文句はもっと短い:

> クレジットを気にするな。$20 を入れろ。仕事に行け。Franklin が必要になったら教えてくれる。

これは公開鍵暗号が 50 年前にやった同じトリックだ。数学者たちが RSA と Diffie-Hellman を発明し、世界に売ったのはアドレスバーの **緑色の鍵** だった。誰も公開鍵暗号を買わない。買うのは「このサイトは安全です」だ。Stripe を世代の会社にしたのは API ではない。7 行のコードと「残りはこちらで」という一文だ。

ウォレットは緑色の鍵だ。私たちが売っているのは「仕事に行け」だ。

## 実際にこれで何ができるか

ウォレット付きエージェントのパターンは、定額モデルでは構造的に不可能な四つを解放する:

### 1. エージェントが正しいツール — 高価なものも含めて — を選ぶ

次の呼び出しが本物のお金を使うとき、エージェントは「その価値があるか」を考えざるを得ない。Franklin のスマートルーターは毎リクエストでこれを行う — プロンプトを見て、答えられそうな最も安いモデルを選び、安いモデルでは失敗するときだけフロンティアにエスカレートする。常に最高モデルとの比較で節約を追跡している; 典型的な週で 60–80%。

サブスクリプションではこれはできない。サブスクリプションの本質は使い方によらず価格が同じだということ。節約する信号がない。だからフラットレート上のエージェントは最も安いモデルにデフォルトする (答えが薄く感じる) か、最も高価なモデルにデフォルトする (途中でスロットリングされる)。

### 2. レート制限を踏まない長時間ループ

自律ループ — スクレイピング、要約、リトライ、分岐 — はモデルでできる最も価値の高いことであり、定額プランに最も合わない。リサーチループ二時間目で打ち切られるところ、ウォレットなら走り続ける。

### 3. 推論ではなくデータを買う

支払いができれば、買えるものは LLM トークンを越える。リアルタイム市場データ、オンチェーン分析、画像生成、動画、ウェブ検索。Franklin はそれらすべてを同じプリミティブとして扱う: [価格タグ付きのツール](/docs/user-guide/tools)。エージェントは有用なときに呼び出す。明細が見える。

### 4. 本当に意味のあるタスク単位の会計

エージェントを走らせた。0.43 ドルかかった。「価値があったか」に答えられる。月をまたいだ平準化なし、「元を取ったか」の悩みなし、月末のサプライズなし。これは退屈に聞こえる。だが、エージェントを社内に展開しようとした財務部のある会社の人なら誰でも、これが最も求められる機能だと教えてくれる。

## 「お金のことを考えたくない」

なら考えなくていい。月一回 $20 を入れるだけ、エージェントは働き、あなたは気にしない。ウォレットは **コストを気にさせる** わけではない; **気にしたいときに気にできる** ようにする。これは厳密により大きな製品だ — サブスクリプションは気にしないことしかできない。

もう一つの選択肢 — API キー駆動のエージェント — は間違ったことを気にさせる。どのプロバイダのキーがどの env ファイルにあるか、どのキーがローテートされたか、どのダッシュボードにログインしてどの残高をリチャージするか。USDC を保持する一つのウォレットなら、見るべき数字は一つ、リフィルする数字も一つ。

## 私たちが賭けているインバリアント

定額 AI は過渡的な製品だ。三年前は暗号レールが整っておらず、クレジットカードは 0.001 セントの推論呼び出しを決済するには粗すぎた。今は整った。x402 はセント — そして 1/10 セント — をネイティブにオンチェーンで決済する。チャージバックリスクなし、プラットフォームの中間配給なし。

レールが機能すれば、すべてのエージェントは最終的に自分の残高を持つ。暗号がクールだからではない、イデオロギー的に正しいからでもない。**定額レーションされたエージェントは、残高に支えられたエージェントに、品質、自律性、そして「あなたが何を買っているか」の正直さで負けるからだ。**

ウォレットは製品ではない。製品はエージェントだ — 仕事をする自由を持った。ウォレットはエージェントが最終的にそれを行えるようにするものだ。
