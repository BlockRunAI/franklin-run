پربازخوردترین شکایت در issue tracker Claude Code این هفته نسخه‌های یک جمله است: **"برای تلاش‌های مجددی که چیزی تولید نکردند پول دادم."**

[Issue #54143](https://github.com/anthropics/claude-code/issues/54143): جلسه `codex:resume` یک کاربر در ۱۲ ساعت ۲۷٪ از حد هفتگی را با پیشرفت صفر سوزاند. [Issue #54177](https://github.com/anthropics/claude-code/issues/54177): "حد مصرف رسید" در حالی که مصرف ۰٪ / ۵٪. [Issue #54190](https://github.com/anthropics/claude-code/issues/54190): تایم‌اوت API توکن‌ها را بدون تکمیل کسر کرد. [Issue #54146](https://github.com/anthropics/claude-code/issues/54146): CLI دستورهای بسیار واضح را دنبال نمی‌کند.

این‌ها باگ‌های تصادفی نیستند. این **حالت شکست ساختاری عامل‌های کدنویسی تک-فروشنده** است: وقتی پشت ابزار شما دقیقاً یک مدل و دقیقاً یک رابطه صورت‌حساب وجود دارد، هر تنزل در هر یک از سیستم‌ها مستقیماً به دوش توسعه‌دهنده‌ای که می‌خواهد منتشر کند می‌افتد.

Franklin روی فرض مخالف ساخته شده است. **چندمدلی یک ویژگی در نقشه راه Franklin نیست. معماری است.** با این فرض، چهار چیز دیگر — لایه رایگان، قیمت‌گذاری مبتنی بر نتیجه، مصونیت در برابر قطعی فروشنده، دسترسی جغرافیایی بدون ثبت‌نام — نه فقط ممکن بلکه اجتناب‌ناپذیر می‌شوند.

## سه مالیات "تک-فروشنده"

**مالیات قطعی فروشنده.** وقتی Anthropic سکسکه می‌کند، Claude Code متوقف می‌شود. دکمه "مدل بعدی" نیست. Cursor در مارس شش ساعت قطع بود.

**مالیات انحراف مدل.** Sonnet تیز ژانویه همان Sonnet آوریل نیست. Anthropic تغییرات منتشر می‌کند.

**مالیات قدرت قیمت‌گذاری.** وقتی عامل و مدل از یک فروشنده هستند، فروشنده سقف قیمت را تعیین می‌کند. می‌تواند تلاش‌های مجدد را شارژ کند، در مصرف کم throttle کند، تنها رفع: "منتظر تجدید حد هفتگی بمان."

عامل چندمدلی هر سه را حذف می‌کند. Anthropic تنزل کرد — Franklin به Grok یا Gemini مسیریابی می‌کند و فراخوان را تکمیل می‌کند. **عامل دیگر روی روز خوب هیچ فروشنده‌ای شرط نمی‌بندد.**

## Smart Router در اعداد ملموس

Smart Router Franklin روی **۲ میلیون درخواست واقعی** آموزش دیده است. هر prompt را طبقه‌بندی می‌کند و مدل با بهترین نسبت کیفیت-هزینه برای آن کلاس را انتخاب می‌کند:

```text
> refactor this auth module to use JWT
  CODING kimi-k2.6  ·  12.4K in / 2.1K out  ·  $0.0023  saved 84%

> what's BTC outlook for the week?
  TRADING grok-4-1-fast-reasoning  ·  8.2K in / 1.8K out  ·  $0.0008  saved 95%

> prove this algorithm is O(n log n)
  REASONING claude-sonnet-4.6  ·  15.1K in / 3.4K out  ·  $0.0312  premium tier
```

چهار پروفایل قابل ثابت‌سازی در جلسه:

| پروفایل | استراتژی | چه زمان |
|---|---|---|
| `auto` | بهترین کیفیت-هزینه | پیش‌فرض |
| `eco` | ارزان‌ترین با کیفیت قابل قبول | حجمی |
| `premium` | بالاترین کیفیت | حیاتی |
| `free` | فقط NVIDIA + Qwen3 | موجودی صفر |

## "رایگان" یک لایه نیست — پیش‌فرض است

اکثر "لایه‌های رایگان" در ابزار هوش مصنوعی، آزمایش پنج روزه با کارت هستند. لایه رایگان Franklin متفاوت است. از **NVIDIA Nemotron و DeepSeek V4 Flash** استفاده می‌کند — واقعاً در منبع رایگان:

```bash
npm install -g @blockrun/franklin
franklin
# مدل‌های رایگان فوراً کار می‌کنند. بدون کیف پول، ایمیل، کارت.
```

فقط زمانی که مدل پیشرو می‌خواهید کیف پول را شارژ می‌کنید. **۵ دلار USDC تمام مدل‌ها و ابزارهای پولی دروازه را باز می‌کند.** بدون اشتراک، بدون حداقل.

## YOPO: پاسخ خط به خط به "برای تلاش‌های مجدد پول دادم که چیزی تولید نکردند"

مدل قیمت‌گذاری Franklin نام دارد — **YOPO، You Only Pay Outcome.** کار می‌کند چون لایه تسویه (x402 روی USDC) به ازای هر فراخوان، آن‌چین، با ریسک چارج‌بک صفر تسویه می‌کند. اگر فراخوان شکست بخورد، تاجر پرداخت را امضا نمی‌کند. کیف پول بدهکار نمی‌شود.

سه نتیجه:

1. **بدون اشتراک.** این هفته ۰.۵۰ دلار، هفته بعد ۵۰ دلار.
2. **بدون محدودیت نرخ.** بدون سقف مصنوعی.
3. **بدون اضافه‌برداشت.** موجودی کیف پول حد سخت است.

ظرفیت واقعی ۱ دلار:

| منبع | برای ۱ دلار |
|---|---|
| توکن‌های ورودی GPT-4o | ~۴۰۰ هزار |
| توکن‌های DeepSeek | ~۷ میلیون |
| توکن‌های Gemini 2.5 Flash | ~۱۳ میلیون |
| تصاویر DALL-E 3 | ~۲۰ |
| جستجوهای Exa | ~۴۰ |
| NVIDIA GPT-OSS / Qwen3 | نامحدود (رایگان) |

## فردا چه می‌کنید

اگر کاربر Claude Code هستید و جلسه‌ای داشتید که بودجه را در تلاش‌های مجدد سوزانده — جایگزین چندمدلی دو دستور است:

```bash
npm install -g @blockrun/franklin
franklin
```

در لایه رایگان NVIDIA Nemotron و DeepSeek V4 Flash، بدون کارت، بدون ثبت‌نام. Sonnet را برای یک وظیفه بپینید — ۵ دلار شارژ کنید و `--profile premium` استفاده کنید. ارائه‌دهنده قطع شد — روتر به بعدی fail-over می‌کند.

[منبع کامل](https://github.com/blockrunai/franklin) در GitHub. [مستندات smart router](/docs/user-guide/smart-router).

شرط Franklin مستقیم است: **عامل‌های کدنویسی تک-فروشنده محصول گذرا هستند.** عامل‌هایی که مسیریابی می‌کنند برنده می‌شوند. تنها سؤال: کی.

اگر این هفته دوباره حد هفتگی شما سوخت — آن "کی"، الآن است.
