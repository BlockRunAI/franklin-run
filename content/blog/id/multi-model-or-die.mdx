Keluhan paling banyak di-upvote di issue tracker Claude Code minggu ini adalah variasi dari kalimat yang sama: **"Saya bayar untuk retry yang tidak menghasilkan apa-apa."**

[Issue #54143](https://github.com/anthropics/claude-code/issues/54143): sesi `codex:resume` pengguna membakar 27% batas mingguan dalam 12 jam dengan progres nol. [Issue #54177](https://github.com/anthropics/claude-code/issues/54177): "Batas pemakaian tercapai" saat pemakaian 0% di window 5 jam dan 5% mingguan. [Issue #54190](https://github.com/anthropics/claude-code/issues/54190): timeout API mengurangi token tanpa penyelesaian. [Issue #54146](https://github.com/anthropics/claude-code/issues/54146): CLI tidak mengikuti instruksi yang sangat jelas — sesi yang sama, tiga retry, tiga kegagalan berbeda, semuanya ditagih.

Ini bukan bug acak. Ini **mode kegagalan struktural dari coding agent vendor tunggal**: ketika ada tepat satu model di belakang tool kamu dan tepat satu hubungan tagihan, setiap degradasi salah satu sistem langsung jatuh ke developer yang sedang berusaha rilis.

Franklin dibangun di premis yang berlawanan. **Multi-model bukan fitur di roadmap Franklin. Itu arsitekturnya.** Dengan premis itu, empat hal lain — tier gratis, harga berbasis hasil, kekebalan terhadap downtime vendor, jangkauan geografis tanpa daftar — bukan hanya mungkin tapi tak terhindarkan.

## Tiga pajak yang kamu bayar untuk "vendor tunggal"

**Pajak vendor down.** Saat Anthropic cegukan, Claude Code berhenti. Tidak ada tombol "model berikutnya." Cursor down enam jam di Maret; ribuan developer hanya menunggu.

**Pajak model drift.** Sonnet yang tajam di Januari bukan Sonnet yang sama di April. Anthropic merilis perubahan. Kadang model baru lebih tajam, kadang mengabaikan instruksi tiga baris di atas — seperti #54146.

**Pajak kekuatan harga.** Saat agent dan model dari vendor sama, vendor mengontrol plafon harga. Bisa menagih retry, throttle pemakaian rendah, dan satu-satunya perbaikan adalah "tunggu reset mingguan."

Agent multi-model menghapus ketiganya. Saat Anthropic terdegradasi, Franklin me-route ke Grok atau Gemini dan menyelesaikan call. **Agent tidak lagi bertaruh pada hari baik vendor tunggal.**

## Smart Router dalam angka

Smart Router Franklin dilatih pada **2 juta request nyata**. Mengklasifikasikan setiap prompt — coding, trading, reasoning, research — dan memilih model dengan rasio kualitas-biaya terbaik untuk kelas itu:

```text
> refactor this auth module to use JWT
  CODING kimi-k2.6  ·  12.4K in / 2.1K out  ·  $0.0023  saved 84%

> what's BTC outlook for the week?
  TRADING grok-4-1-fast-reasoning  ·  8.2K in / 1.8K out  ·  $0.0008  saved 95%

> prove this algorithm is O(n log n)
  REASONING claude-sonnet-4.6  ·  15.1K in / 3.4K out  ·  $0.0312  premium tier
```

Empat profil per session:

| Profil | Strategi | Untuk |
|---|---|---|
| `auto` | Rasio kualitas-biaya terbaik | Default |
| `eco` | Termurah dengan kualitas oke | Bulk, eksplorasi |
| `premium` | Kualitas tertinggi | Mission-critical |
| `free` | NVIDIA + Qwen3 saja | Saldo dompet 0 |

## "Gratis" bukan tier — itu default

Tier "gratis" kebanyakan AI tools adalah trial 5 hari dengan kartu di file. Tier gratis Franklin beda. Pakai **NVIDIA Nemotron dan Qwen3 Coder** — yang asli gratis di sumbernya.

```bash
npm install -g @blockrun/franklin
franklin
# model gratis langsung jalan. tanpa dompet, email, kartu.
```

Kamu hanya isi dompet saat ingin model frontier. **$5 USDC membuka semua model dan tool berbayar di gateway.** Tanpa langganan, tanpa minimum.

Kenapa kami bisa, Cursor tidak: Cursor butuh kartu karena ekonominya bergantung pada bundling. Ekonomi kami bekerja karena **kami tidak bayar untuk model gratis** — sudah gratis di sumbernya.

Konsekuensi strategis: **biaya mencoba Franklin nol, dan biaya terus pakai untuk task murah juga nol.**

## YOPO: jawaban per-baris untuk "saya bayar untuk retry yang tidak hasilkan apa-apa"

Model harga Franklin punya nama untuk ini — **YOPO, You Only Pay Outcome.** Bekerja karena layer pembayaran (x402 pada USDC) menyelesaikan per-call, on-chain, tanpa risiko chargeback. Kalau call gagal, merchant tidak menandatangani pembayaran. Dompet tidak didebit.

Tiga konsekuensi:

1. **Tanpa langganan.** Minggu ini $0,50, minggu depan $50.
2. **Tanpa rate limit.** Tanpa plafon buatan.
3. **Tanpa overdraft.** Saldo dompet adalah batas keras.

$1 dalam kapasitas nyata:

| Sumber daya | Untuk $1 |
|---|---|
| Token input GPT-4o | ~400K |
| Token DeepSeek | ~7 juta |
| Token Gemini 2.5 Flash | ~13 juta |
| Gambar DALL-E 3 | ~20 |
| Pencarian Exa | ~40 |
| NVIDIA GPT-OSS / Qwen3 | tanpa batas (gratis) |
