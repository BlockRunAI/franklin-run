أكثر شكوى مُؤيَّدة في issue tracker لـ Claude Code هذا الأسبوع هي صياغات لجملة واحدة: **"دفعت ثمن إعادات محاولة لم تنتج شيئًا."**

[Issue #54143](https://github.com/anthropics/claude-code/issues/54143): جلسة `codex:resume` أحرقت 27% من الحد الأسبوعي خلال 12 ساعة دون تقدم. [Issue #54177](https://github.com/anthropics/claude-code/issues/54177): "تجاوزت الحد" عند 0% / 5%. [Issue #54190](https://github.com/anthropics/claude-code/issues/54190): انقطاع API يخصم رموزًا بدون إكمال. [Issue #54146](https://github.com/anthropics/claude-code/issues/54146): الـ CLI لا يتبع التعليمات الواضحة جدًا — نفس الجلسة، 3 إعادات، 3 إخفاقات مختلفة، كلها مدفوعة.

هذه ليست أخطاء عشوائية. إنها **النمط الفشلي البنيوي لوكلاء البرمجة ذوي البائع الواحد**: عندما يكون خلف الأداة نموذج واحد وعلاقة فوترة واحدة، أي تدهور في أي من النظامين يقع مباشرة على المطور الذي يحاول الشحن.

Franklin مبني على الفرضية المعاكسة. **تعدد النماذج ليس ميزة في خارطة طريق Franklin. إنه المعمارية.** بهذه الفرضية، الأربعة الأخرى — التيار المجاني، التسعير القائم على النتائج، حصانة من تعطل البائع، الوصول الجغرافي بدون تسجيل — تصبح ليست فقط ممكنة بل حتمية.

## الضرائب الثلاث للبائع الواحد

**ضريبة تعطل البائع.** عند انقطاع Anthropic، يتوقف Claude Code. لا زر "النموذج التالي." Cursor تعطل ست ساعات في مارس.

**ضريبة انجراف النموذج.** Sonnet الحاد في يناير ليس نفس Sonnet في أبريل. أحيانًا أحدّ، أحيانًا يتجاهل تعليمات قبل ثلاثة أسطر — كما في #54146.

**ضريبة قوة التسعير.** عندما يكون الوكيل والنموذج من البائع نفسه، يتحكم البائع في سقف السعر. يحاسب على إعادة المحاولات ويُبطّئك في استخدام منخفض. الإصلاح الوحيد: انتظر تجديد الحد الأسبوعي.

الوكيل متعدد النماذج يزيل الثلاثة. عند تدهور Anthropic، يوجّه Franklin إلى Grok أو Gemini ويكمل الاستدعاء. **الوكيل لم يعد يراهن على يوم جيد لأي بائع منفرد.**

## Smart Router بأرقام ملموسة

تم تدريب Smart Router من Franklin على **2 مليون طلب حقيقي**. يصنّف كل مطالبة ويختار النموذج بأفضل نسبة جودة-تكلفة لتلك الفئة:

```text
> refactor this auth module to use JWT
  CODING kimi-k2.6  ·  12.4K in / 2.1K out  ·  $0.0023  saved 84%

> what's BTC outlook for the week?
  TRADING grok-4-1-fast-reasoning  ·  8.2K in / 1.8K out  ·  $0.0008  saved 95%

> prove this algorithm is O(n log n)
  REASONING claude-sonnet-4.6  ·  15.1K in / 3.4K out  ·  $0.0312  premium tier
```

أربعة ملفات تعريف لكل جلسة:

| ملف التعريف | الاستراتيجية | متى |
|---|---|---|
| `auto` | أفضل نسبة جودة-تكلفة | افتراضي |
| `eco` | الأرخص بجودة مقبولة | كميات كبيرة |
| `premium` | أعلى جودة | حرج |
| `free` | NVIDIA + Qwen3 فقط | رصيد صفر |

## "المجاني" ليس درجة، إنه الافتراضي

معظم "الدرجات المجانية" في أدوات الذكاء الاصطناعي تجارب لمدة 5 أيام مع بطاقة. درجة Franklin المجانية مختلفة. تستخدم **NVIDIA Nemotron و DeepSeek V4 Flash** — مجانية فعلاً عند المصدر:

```bash
npm install -g @blockrun/franklin
franklin
# النماذج المجانية تعمل فورًا. بدون محفظة، بريد، بطاقة.
```

تُموّل المحفظة فقط عندما تريد نماذج الجبهة الأمامية. **$5 USDC تفتح كل النماذج والأدوات المدفوعة في البوابة.** بدون اشتراك، بدون حد أدنى.

## YOPO: الجواب البندي على "دفعت لإعادات لم تنتج شيئًا"

لنموذج تسعير Franklin اسم — **YOPO، You Only Pay Outcome.** يعمل لأن طبقة التسوية (x402 على USDC) تسوّي عند كل استدعاء، على السلسلة، بدون مخاطر استرداد. إذا فشل الاستدعاء، التاجر لا يوقّع الدفعة. المحفظة لا تُخصم.

ثلاث نتائج تترتب:

1. **بدون اشتراك.** هذا الأسبوع $0.50، التالي $50.
2. **بدون حد معدل.** بدون أسقف اصطناعية.
3. **بدون سحب على المكشوف.** رصيد المحفظة هو الحد الصلب.

ما يساوي $1 من السعة الفعلية:

| المورد | لـ $1 |
|---|---|
| رموز إدخال GPT-4o | ~400 ألف |
| رموز DeepSeek | ~7 ملايين |
| رموز Gemini 2.5 Flash | ~13 مليون |
| صور DALL-E 3 | ~20 |
| عمليات بحث Exa | ~40 |
| NVIDIA GPT-OSS / Qwen3 | غير محدود (مجاني) |

## ما تفعله غدًا

إذا كنت مستخدم Claude Code وأحرقت جلستك ميزانيتك على إعادات المحاولة — البديل متعدد النماذج أمران:

```bash
npm install -g @blockrun/franklin
franklin
```

ستعمل على الدرجة المجانية مع NVIDIA Nemotron و DeepSeek V4 Flash، بدون بطاقة، بدون تسجيل. أردت تثبيت Sonnet لمهمة واحدة — موّل $5 واستخدم `--profile premium`. النموذج انجرف — بدّل الملف. المزود تعطل — الـ router يفشل إلى التالي.

[المصدر الكامل](https://github.com/blockrunai/franklin) على GitHub. [وثائق الموجه الذكي](/docs/user-guide/smart-router).

رهان Franklin مباشر: **وكلاء البرمجة من بائع واحد منتج انتقالي.** الوكلاء الذين يوجّهون سيفوزون. السؤال الوحيد: متى.

إذا أحرق حدّك الأسبوعي مرة أخرى هذا الأسبوع — تلك اللحظة هي الآن.
